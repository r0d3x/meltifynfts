## 🏃‍♂️ Quick Steps to Run

1. **Start the frontend** (already working):
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` to see the app!

2. **To enable minting** (deploy smart contract):
   ```bash
   # Install Sui CLI first
   # Then run:
   ./scripts/deploy.sh
   ```
